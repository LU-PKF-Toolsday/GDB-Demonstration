# Toolsday GDB demonstration

This repository contains code that will be used during the Toolsday GDB demonstration.

In order to compile the code, do the following:

1. mkdir build
2. cd build
3. cmake ../
4. cmake --build .

Optionally, run 

5. cmake --install .

See details in CMakeLists.txt

# Find the bugs

The code contains a large amount of intentional bugs (and who knows how many unintentional ones...).
Try using GDB to detect them!
